# 验收 1：合并单元格展开

## 自造样例（横向 A2:C2 = 3 格，纵向 A3:A4 = 2 行）

横向合并区域 A2:C2 -> ['横向合并三格', '横向合并三格', '横向合并三格']
纵向合并区域 A3:A4 -> A3='纵向合并两行' A4='纵向合并两行'

## 样例价目表 samples/pricelist.xlsx

纵向合并 F2:F3 -> F2='华东' F3='华东'
横向合并 C12:E12 -> ['组合优惠：任选三件九折（已含税）', '组合优惠：任选三件九折（已含税）', '组合优惠：任选三件九折（已含税）']

结论：两个合并区域内每格都等于锚点值且非空。
